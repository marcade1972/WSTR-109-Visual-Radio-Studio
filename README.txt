WSTR 109 Visual Radio Studio

Timeless Stories. Endless Adventures.

WSTR 109 Visual Radio Studio is a Windows desktop application createdfor WSTR 109 Stardust OTR Radio. It transforms classic old-timeradio episodes into immersive visual-radio presentations using timedscene artwork, cinematic motion, audio visualization, and Full HD videorendering.

The goal is not to turn radio drama into television. Visual Radio isdesigned to complement the story while preserving the most powerful partof old-time radio: the listener's imagination.

Close your eyes. Open your imagination.

About the Project

Old-time radio can create entire worlds using nothing more than voices,music, sound effects, and imagination.

A creaking door can become any door.A distant train can travel through any landscape.A mysterious transmission can come from anywhere in the universe.

WSTR 109 Visual Radio Studio gives these stories a visual companionwithout replacing the pictures created in the listener's mind.

Instead of displaying one static image throughout an episode, theapplication allows creators to build a timeline of atmospheric scenesthat change as the story progresses. Images can move subtly through pansand zooms, transition between scenes, and be accompanied by an audiowaveform visualization.

Scene-Based Visual Radio

Visual Radio allows a single radio episode to become a sequence ofvisual moments.

For example, a science-fiction story could progress through:

Opening episode artwork

Spacecraft leaving Earth

Approaching another planet

An unknown object appearing

The mysterious object moving closer

A disturbing transmission

The crew reacting

Returning toward Earth

Discovering a changed world

A final atmospheric scene

Each scene can have its own start time, artwork, size, and motion.

The Auto Space feature can distribute scene images throughout theepisode automatically, after which the timing can be adjusted manually.

Timeline Scrubbing

The timeline scrubber makes it possible to move through an episode whilebuilding the visual presentation.

This helps place artwork where it belongs in the story rather thanrelying only on estimated timestamps.

Individual scenes can also be resized so artwork fits the 16:9 videoframe appropriately.

Audio Visualization

The built-in audio visualizer provides subtle motion based on theepisode audio.

Visualizer options include:

Waveform style

Position

Height

Opacity

Accent appearance

The visualizer is intended to enhance the presentation withoutoverpowering the radio drama itself.

Video Rendering

WSTR 109 Visual Radio Studio uses FFmpeg for final video creation.

The application supports Full HD 1920 × 1080 output and providesrendering information including:

Percentage complete

Current episode position

Encoding speed

Elapsed rendering time

Estimated time remaining

CPU H.264 encoding is available, along with supported hardware encodingoptions depending on the computer's graphics hardware and FFmpegconfiguration.

FFmpeg

The application expects the required FFmpeg executables in its Toolsfolder:

ffmpeg.exe

ffprobe.exe

If FFmpeg cannot be found, video rendering will not be available.

FFmpeg is a separate open-source project. Users should obtain FFmpegfrom an appropriate official or trusted distribution and comply with itsapplicable license terms.

Building the Application

WSTR 109 Visual Radio Studio is a Windows/.NET application.

A typical development environment includes:

Windows 10 or Windows 11

.NET SDK

C# / WinForms

Visual Studio Code or Visual Studio

FFmpeg for video rendering

The repository may include a build batch file. When present, run:

BUILD-WSTR-VISUAL-RADIO.bat

Keep the application's required asset folders with the compiledapplication.

The Philosophy Behind Visual Radio

Movies show you the world.

Radio asks you to create it.

When a radio character walks into an abandoned house, there is no singleabandoned house. Every listener creates a different one.

That creative participation is one of the things that made the GoldenAge of Radio extraordinary.

WSTR 109 Visual Radio is built around a simple idea:

Imagination is more powerful than any screen.

The artwork provides atmosphere.The audio provides the story.Your imagination does the rest.
