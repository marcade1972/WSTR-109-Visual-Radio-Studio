WSTR 109 Visual Radio Studio v0.6.2 Alpha 6b
CABINET TIGHT FIT

THIS BUILD ADDRESSES THE GAP BETWEEN THE LIVE WINFORMS AND THE CABINET.

CHANGES
- Tightened the cabinet working-area coordinates.
- Removed the transparent horizontal band between the upper work area and lower console.
- Live Scene Timeline now begins immediately beneath Episode Settings / Preview.
- Live Audio Visualizer now begins immediately beneath the Preview bay.
- Dark live panels cover the cabinet's baked-in placeholder buttons and controls.
- Added a thin bronze separator between the upper and lower live work regions.
- Reduced unnecessary panel margins and padding.
- Adjusted upper Settings / Preview split and lower Timeline / Visualizer split.
- Cabinet artwork updated to the approved tight-fit visual reference.

FUNCTIONAL FEATURES RETAINED
- Series profiles
- MP3 and artwork selection
- Artwork Type / Artwork Fit preview
- Scene Timeline
- Auto Space Scenes
- Scene motion presets
- Timeline save/load
- Audio-reactive waveform
- Waveform preview
- CPU / hardware encoder selection
- FFmpeg rendering
- Render progress, speed, elapsed time, and ETA

BUILD
Run BUILD-WSTR-VISUAL-RADIO.bat.
Keep the Assets folder with the application output.
Keep ffmpeg.exe and ffprobe.exe in Tools beside the running EXE.
